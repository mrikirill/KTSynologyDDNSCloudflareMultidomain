## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it to us responsibly.

### How to Report

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, please report them by emailing [kirill@osome.dev](mailto:kirill@osome.dev). You should receive a response within 48 hours.

### What to Include

*   A description of the vulnerability.
*   Steps to reproduce the issue.
*   Any relevant logs or screenshots.
*   Potential impact of the vulnerability.

### Disclosure Policy

*   We will investigate the report and determine the severity of the issue.
*   We will work to fix the vulnerability as quickly as possible.
*   We ask that you do not disclose the vulnerability publicly until we have had a chance to fix it.
